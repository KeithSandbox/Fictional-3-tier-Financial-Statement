# Startup Financial Model: Karibu Juice Stand

A three-statement financial model for a **fictional** small business,
built in Excel as part of my journey into startup financial modeling.

## What it does
- Forecasts 12 months of revenue, costs and profit
- Tracks a bank loan and the interest on it
- Builds a balance sheet and cash flow statement that balance every month

## Tabs
| Tab | Purpose |
|---|---|
| Setup | Opening balance sheet |
| Assumptions | All inputs (price, costs, growth, loan) in one place |
| IS | Income statement and loan schedule |
| BS | Balance sheet with a check row |
| CF | Cash flow statement |

## Key results (fictional data)
- Year 1 revenue: about KES 2.13 million
- Year 1 net profit: about KES 645,000
- Closing cash: about KES 809,000

## How to use
Open the Excel file and change the blue cells on the Assumptions tab.
Everything else updates automatically.
